## ✦ Overview

**ECHO** is a modern editorial portfolio designed and engineered for **Nishant Verma**, a Computer Science undergraduate and Full-Stack Developer. Focused on clean typographic hierarchy, fluid physics, and cutting-edge web graphics, the portfolio marries brutalist minimalism with rich micro-interactions, hardware-accelerated scroll kinematics, and interactive 3D drum navigation.

The portfolio is structured around Nishant's core engineering achievements, academic credentials, verified SAP certifications, and full-stack software applications built with **React.js, Node.js, Express.js, MySQL, Neon PostgreSQL, and REST APIs**.

## ✦ Key Sections & Interactive Architecture

### 1. 🪐 Orbital Preloader & Editorial Hero
- **Orbital Animation**: Lightweight canvas intro with wavy dot particle physics synchronized via `requestAnimationFrame`.
- **Editorial Typography**: Responsive typographic scaling driven by dynamic viewport calculations (`clamp` / `vw`) and multi-stop metallic linear gradients.
- **Portrait Depth Masking**: Smooth alpha gradient transition integrating personal portraiture cleanly into the monochrome stage.

### 2. 🔍 `ScrollExpandMedia` Kinetic Canvas (`#about`)
- **Scroll-Driven Media Stage**: Dynamically expands and scales container geometry, aspect ratio, and backdrop contrast in sync with vertical scroll progress.
- **Dual-Layer GPU Unblur**: Smoothly interpolates pre-blurred imagery into crystal-clear resolution at 60/120 FPS with zero layout reflow.
- **Perimeter Typography & Narrative**: Text elements smoothly translate outward on the X-axis while revealing Nishant's developer profile, philosophy, and focus areas.

### 3. 🧭 Horizontal Spatial Education Timeline (`#education`)
- **Spatial Progression Engine**: Sticky full-viewport canvas translating vertical scroll into smooth horizontal progression (`experience-section.js`).
- **Academic Qualifications**:

  - **Secondary & Higher Secondary Education** — *Mar Gregorios Memorial School*. Class XII Science Stream (March 2023) and Class X (May 2021).
- **Living Flow & Parallax**: Parallax background typography (`2023 — 2027`) and smooth milestone indicator counters.

### 4. 🌊 FlexCarousel WebGL Liquid Card Slider (`#projects`)
- **OGL WebGL Shaders**: Interactive card slider powered by [OGL](https://github.com/oframe/ogl) running liquid lens mesh displacement, bend curvature presets, and real-time cursor distortion.

- **Interactive Project Inspection Modal**: Glassmorphic modal viewer presenting complete project dossiers, system architectures, deliverables, tech stacks, and live GitHub links.

### 5. 🎡 WorksWheel 3D Drum Reel (`#certifications`)

## ✦ Getting Started Locally

The project runs using standard ES modules and modern browser web standards. No complex compile pipeline is required to run the site locally.

### Prerequisites
- Python 3.x **or** Node.js installed on your machine.

### Option 1: Python Simple HTTP Server (Fastest)
```bash
# Clone the repository
git clone https://github.com/Vermaji2077/ECHO-WEBSITE.git
cd ECHO-WEBSITE

# Start local server
python -m http.server 8080
```
Open **`http://localhost:8080`** in your browser.

### Option 2: Node.js / Vite / `npx serve`
```bash
# Using npx serve
npx serve .

# Or using live-server for auto-reloading
npx live-server
```

## ✦ Deployment

Because the portfolio is built on standard static web technologies with native ES modules, it can be deployed instantly:

- **GitHub Pages**:
  1. Push code to the `main` branch of `Vermaji2077/ECHO-WEBSITE`.
  2. Navigate to **Settings > Pages**.
  3. Under **Branch**, select `main` and root directory `/`, then click **Save**.
- **Vercel**: Run `vercel` from the project root or import the repository via the Vercel dashboard.
- **Netlify**: Connect your repository or drag-and-drop the directory directly onto Netlify drop.
